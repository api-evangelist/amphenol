# Amphenol

> Amphenol Corporation designs, manufactures and markets electrical, electronic and fiber optic
> connectors, interconnect systems, antennas, sensors and cables for the military-aerospace,
> industrial, automotive, IT and datacom, mobile, broadband, medical and audio markets. It is a
> component manufacturer, not a software vendor, and it runs no developer programme: there is no
> developer portal, no API documentation, no signup, no API key and no published contract.

This file is an API Evangelist roll-up. It is NOT served by Amphenol. Amphenol does publish its
own llms.txt on three of its division hosts; those are saved verbatim alongside this file and
are the authoritative provider-authored versions.

## Provider-published llms.txt (verbatim copies)

- [Amphenol Sensors llms.txt](amphenol-sensors-llms.txt): fetched from https://amphenolsensors.com/llms.txt (HTTP 200). Hand-authored; maps 25 sensing brands to measurements and markets.
- [Amphenol Industrial llms.txt](amphenol-industrial-llms.txt): fetched from https://amphenol-industrial.com/llms.txt (HTTP 200). Generated by Rank Math SEO; enumerates product categories and ~65 connector product pages.
- [Amphenol Automotive llms.txt](amphenol-automotive-llms.txt): fetched from https://amphenol-automotive.com/llms.txt (HTTP 200). Hand-authored "GEO optimized" content map with a Q&A block.

## API surfaces that actually exist

Neither is documented by Amphenol. Both were found by probing and confirmed on the wire.

- Amphenol Industrial Parts Direct Search — `GET https://amphenol-industrial.com/wp-json/parts-direct-search/v1/search?searchTerm=<part>`. Anonymous, no key, returns JSON `{total, rows[]}` of authorised-distributor stock for an Amphenol part number: distributor, distributor SKU, quantity on hand, last-updated timestamp and a deep buy link. One parameter only; no pagination. Backs the human page at https://amphenol-industrial.com/connectors/parts-search/.
- Amphenol Automotive MCP server — `https://amphenol-automotive.com/wp-json/mcp/mcp-oauth-server`. A live Model Context Protocol resource behind OAuth 2.0 authorization-code with PKCE, advertised via RFC 8414 and RFC 9728 metadata at that host's `/.well-known/`. Single scope `mcp`. An anonymous `tools/list` returns 401, so the tool set is not public.

## What does not exist

- No OpenAPI, Swagger, GraphQL, AsyncAPI, gRPC or WSDL contract on any reachable host.
- No A2A agent card at `/.well-known/agent-card.json` or `/.well-known/agent.json`.
- No security.txt, no api-catalog, no trust centre, no vulnerability disclosure programme.
- No status page, changelog, deprecation policy, SLA or developer support channel.
- No API client SDK on npm, PyPI, RubyGems, NuGet, Maven Central, crates.io or pkg.go.dev, and no public Postman collection.
- No rate-limit documentation and no rate-limit response headers.

## First-party code (hardware, not API clients)

- [Amphenol Advanced Sensors](https://github.com/AmphenolAdvancedSensors): Arduino/C++ drivers for Telaire, Thermometrics and NovaSensor parts, plus evaluation-kit firmware.
- [Amphenol Borisch Technologies](https://github.com/Amphenol-Borisch-Technologies): C#/Python test-automation libraries (TestExecutive, TestPlan, TDK-Lambda power-supply control). None is published to a package registry, and none has ever cut a release or a tag.

## Access notes for crawlers

www.amphenol.com, amphenol.com, www.amphenolrf.com, amphenol-aerospace.com,
www.amphenolcanada.com and investors.amphenol.com return HTTP 403 "Access Denied" from the CDN
edge to non-browser clients on every path, including /robots.txt. The division hosts
amphenolsensors.com, amphenol-industrial.com and amphenol-automotive.com are open, and
amphenol-automotive.com/robots.txt explicitly allows GPTBot, Google-Extended, PerplexityBot,
ClaudeBot, CCBot, Bytespider and Amazonbot.
